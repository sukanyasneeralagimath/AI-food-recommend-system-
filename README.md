🤖 AI Food Recommendation System

An interactive web application that recommends food based on the user's mood. The project provides a simple and attractive interface with food suggestions, animations, images, and voice output.

✨ Features

- 😊 Mood-based food recommendations
- 🍕 Different food suggestions
- 🎲 Try Another Food option
- 🔊 Voice recommendation using Speech Synthesis
- 🎉 Confetti animation
- ⏳ Loading animation
- 📜 Recommendation history
- 📱 Responsive design
- 🖼️ Food images
- 🌈 Animated gradient background
- ✨ Glassmorphism user interface

🧠 Available Moods

- Happy
- Sad
- Tired
- Romantic
- Sick
- Party
- Gym

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

🚀 How to Run the Project

1. Clone the repository

git clone https://github.com/sukanyasneeralagimath1-code/AI-food-recommend-system-.git

2. Open the project folder

cd AI-food-recommend-system-

3. Install dependencies

npm install

4. Start the server

node server.js

5. Open in browser

http://localhost:3000

🎯 Purpose of the Project

The main purpose of this project is to demonstrate how a simple web application can use JavaScript logic to provide personalized food recommendations based on a user's mood.
